# Challenge poster cutouts

Implemented from the user's 5 November 2026 video reference: wide rounded gradient cards, distinct realistic figures above the top edge, a fading lower silhouette, readable left titles, and full-width white actions. The Training carousel and Challenge list share `ChallengePosterCard`.

All eleven catalog challenges have their own original cutout. Four female artwork variants preserve the existing gender selection behavior. Customized workouts use the exact catalog image where available, otherwise an equipment/focus-appropriate cutout. Workout durations and counts remain computed from the playable plan. Only the reference Belly card says Day 1; other cards retain their real Start Workout destination.

Artwork was generated with the built-in imagegen tool, not the CLI. All assets are saved in `assets/images/workouts/poster_*.png`; no files depend on the generator cache. Existing assets remain intact so a running Flutter session does not reference deleted files.
